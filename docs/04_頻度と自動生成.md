# 04. 頻度（曜日）と「今日のチェック」自動生成

「業務マスタを更新するだけで、全店舗の“今日のチェック”が自動で変わる」仕組みの中核です。

## 1. 考え方：役割分担

| 層 | 実体 | 役割 |
|---|---|---|
| **選ぶ頭脳（関数だけ）** | `本日の対象（自動）` シート | 業務マスタから「今日やる業務」を **FILTER＋曜日判定** で自動抽出。誰でも中身を検証できる |
| **チェック＆記録** | `本日のチェック` シート（GAS） | 実際に✓を付ける／完了時刻と履歴を記録。※数式の結果セルには✓を置けないため分離 |

両者は**まったく同じ曜日ルール**で動くので、常に同じ業務が並びます。
100店舗は「業務マスタを直す」だけで全店の今日のチェックが変わります。

## 2. 頻度（`業務マスタ` の「頻度」列）の書き方

| 書き方 | 意味 | 例 |
|---|---|---|
| `毎日` | 毎日必ず表示 | 清掃、売上確認 |
| `毎回` | 都度発生（施術ごと等）。毎日表示 | カルテ記入、39メール |
| 曜日1つ | その曜日だけ表示 | `月` … 毎週月曜だけ |
| 曜日を複数 | 指定した曜日に表示 | `月,木` / `月水金`（区切りは任意） |

- 今日が**月曜**なら → `毎日` `毎回` `月`（＋`月`を含む `月,木` 等）の業務だけが自動表示
- 今日が**火曜**なら → `毎日` `毎回` `火`（＋`火`を含むもの）だけが自動表示

> 入力は業務マスタ「頻度」列のプルダウンから選べます。
> 複数曜日（`月,木`）は手入力でOK（プルダウンは警告が出ますがそのまま入力できます）。

## 3. 判定に使っている数式（そのまま流用可）

`本日の対象（自動）` シートの先頭セルに入っています。

```
=IFERROR(
  FILTER('業務マスタ'!A2:G,
    ARRAYFORMULA(
      ('業務マスタ'!H2:H=TRUE) *
      REGEXMATCH('業務マスタ'!E2:E & "", "毎日|毎回|" & MID("日月火水木金土", WEEKDAY(TODAY()), 1))
    )
  ),
  "対象業務がありません（業務マスタの頻度/有効を確認）")
```

仕組み：
- `MID("日月火水木金土", WEEKDAY(TODAY()), 1)` … 今日の曜日1文字（例：月）
- `REGEXMATCH(頻度, "毎日|毎回|月")` … 頻度が「毎日 or 毎回 or 月」を含めばTRUE
- `H:H=TRUE`（有効列）と掛け合わせ、TRUEの行だけ `FILTER` で抽出
- 列 A:G（ID／区分／業務名／目安／頻度／必須／備考）をそのまま表示

「毎日」は文字として「日」を含みますが、判定は常にTRUE（毎日表示）で正しく動きます。

## 4. マスタ更新が即反映される流れ

1. `業務マスタ` を編集（業務追加・頻度変更・有効ON/OFF）
2. `本日の対象（自動）` … 数式なので**その場で自動更新**
3. `本日のチェック` … マスタ編集を検知して**GASが自動で作り直し**
   （すでに付けた✓は「日次ログ」から復元されるので消えません）
4. 毎朝6時の自動処理でも当日分が再生成されます

## 5. 100店舗運用のポイント

- 全店で**同じコード＋同じ数式**。店舗ごとに変えるのは `Config.gs` の店舗IDだけ
- 「本部で業務マスタを配る／統一する」運用にすれば、頻度や曜日を本部が一括管理でき、
  全店の当日タスクを揃えられます（発展形は `docs/02_マルチ店舗展開.md`）

## 6. 応用（必要になったら）

- **祝日だけ除外**したい → 頻度に加えて祝日カレンダー参照列を足す
- **隔週・月初だけ**などの周期 → `WEEKNUM` や `DAY(TODAY())` を条件に追加
- 上記はいずれも同じFILTERの条件に足すだけで拡張できます

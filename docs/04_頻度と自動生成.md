# 04. 頻度と「今日のチェック」の自動生成

「`各業務マスター` を更新するだけで、今日のチェックが自動で変わる」仕組みの中核です。

## 1. 流れ

```
各業務マスター を編集
   ↓  onEdit トリガー（⏰ 自動化トリガーを設定 で有効になる）
normalizeMaster_()   … 空欄を自動補完（ID採番／頻度＝毎日／有効＝ON など）
   ↓
getScheduledTasks_(今日)  … 「頻度」で今日やる業務だけ抽出、区分順に並べ替え
   ↓
buildChecklist_()    … 今日のチェックを作り直す
                       （✓・完了時刻・担当・メモは引き継ぐ）
```

`今日のチェック` は数式ではなく GAS が作ります。
チェックボックスは数式の結果セルには置けないためです。
代わりに、**マスターの編集・シートを開いた時・毎朝** の3つのタイミングで作り直されます。

## 2. 頻度の書き方（`各業務マスター` の「頻度」列）

| 書き方 | 意味 | 例 |
|---|---|---|
| `毎日` | 毎日表示 | 清掃、売上確認 |
| `毎回` | 都度発生（施術ごと等）。毎日表示 | カルテ記入、39メール |
| （空欄） | 毎日表示（追加直後に消えないように） | |
| `平日` | 月〜金 | 銀行対応 |
| `土日` / `週末` | 土・日 | 週末だけの準備 |
| 曜日1つ | その曜日だけ | `月` … 毎週月曜 |
| 曜日を複数 | 指定した曜日 | `月,木` / `月水金`（区切りは任意） |
| `月末` / `末日` | その月の最終日だけ | 棚卸し |
| `毎月15日` / `15日` | 毎月その日だけ（複数可 `1日,15日`） | 給与計算 |

### 紛らわしいケースの扱い

| 入力 | 判定 |
|---|---|
| `月末` | **月末日**。曜日の「月（月曜）」とは判定しません |
| `毎月15日` | 15日。曜日の「日（日曜）」とは判定しません |
| `毎日` | 毎日。「日曜」とは判定しません |
| `毎週火` | 火曜（`毎週` は無視されます） |

判定は `Common.gs` の `isScheduledOn_()` にまとまっています。
`npm test` で 17パターンの判定を自動検証しています。

## 3. 反映されるタイミング

| きっかけ | 何が起きるか |
|---|---|
| `各業務マスター` を編集 | その場で `今日のチェック` を作り直す |
| `設定` を編集 | 設定を読み直して表示を更新 |
| スプレッドシートを開く | 表示中の日付が今日でなければ作り直す |
| 毎朝（既定6:00） | 前日を `履歴` に確定 → 当日分を用意 |
| メニュー **🔄 マスターの内容を反映** | 手動で作り直す |

> どのタイミングでも、**すでに付けた ✓ は消えません**。
> 画面の状態と `履歴` の記録の両方から復元します。

## 3.5. 目安時間の扱い

マスターの「目安時間（目安(分)）」列は、次の書き方をすべて分に変換して読み取ります。

| マスターの値 | 読み取り |
|---|---|
| `5` | 5分 |
| `5分` / `１５分` | 5分 / 15分 |
| `1時間30分` | 90分 |
| `約5分程度` | 5分 |
| `10 min` | 10分 |
| 時刻セル `0:05` | 5分 |
| 空欄 / 読めない値 | 0分 |

`今日のチェック` の `目安(分)` 列には**分の数値**が入ります（合計してダッシュボードの
「想定作業時間」に使うため）。マスター側の書き方は書き換えません。

## 4. 並び順

1. 区分（`開店前` → `営業中` → `閉店前`）
2. 同じ区分の中では `各業務マスター` の**行の並び順**

マスターの行を並べ替えれば、チェック画面の順番もそのまま変わります。

## 5. 多店舗運用のポイント

- 全店で**同じコード**。店舗ごとに変えるのは `設定` タブだけ
- 本部が業務マスターの内容を配れば、頻度・曜日を本部が一括管理できます
- 発展形は [`02_マルチ店舗展開.md`](02_マルチ店舗展開.md)

## 6. 応用（必要になったら）

- **祝日を除外** … 祝日カレンダーを参照して `isScheduledOn_()` に条件を追加
- **隔週** … 週番号（`WEEKNUM` 相当）を使った条件を追加
- いずれも `isScheduledOn_()` 1か所を直すだけで全体に効きます

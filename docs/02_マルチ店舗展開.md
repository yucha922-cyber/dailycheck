# 02. マルチ店舗展開（100店舗の一元管理）

## 全体像

```
[渋谷店 Sheet+GAS] ─┐
[新宿店 Sheet+GAS] ─┼─ 毎晩サマリ1行を送信 ─▶ [本部 集約Sheet]
[池袋店 Sheet+GAS] ─┘                          └「店舗別サマリ」に全店が集まる
        …                                        └ ダッシュボードでランキング/未達アラート
       ×100
```

- **各店舗**：同じコードを使い、`設定` タブの「店舗ID」「店舗名」だけ変える
- **本部**：スプレッドシート1つ。各店の `設定` タブ「本部集約スプレッドシートID」にそのIDを入力
- 毎晩（既定20:30 / `nightlyCloseJob`）に各店 → 本部へ「その日1行のサマリ」を upsert 送信

送信されるサマリ（`店舗別サマリ` シート）:

| 日付 | 店舗ID | 店舗名 | 完了率 | 完了数 | 総数 | 未完了数 | 未完了業務 | 更新時刻 |
|---|---|---|---|---|---|---|---|---|

## セットアップ手順

### 1. 本部の集約スプレッドシートを用意
1. 新規スプレッドシートを作成（例：「本部_業務集約」）
2. URL の `/d/★★★/edit` の `★★★` が **集約シートID**
3. 各店舗のGAS実行アカウントに、この集約シートの**編集権限**を共有

### 2. 各店の設定
各店の `設定` タブに入力します（コードは触りません）。

| 項目 | 値の例 |
|---|---|
| 店舗ID | `STORE_012`（店舗ごとに一意） |
| 店舗名 | `渋谷店` |
| 本部集約スプレッドシートID | `★集約シートID★`（全店共通） |

`⏰ 自動化トリガーを設定` 済みなら、以後は自動送信。手動送信は
`☁ 本部へ今日のサマリを送信`。

### 3. 本部ダッシュボード（雛形）
集約シートに `本部ダッシュボード` を作り、次のような数式で当日状況を集計できます
（`店舗別サマリ` 前提）。

```
今日の日付:            =TODAY()
本日の提出店舗数:      =COUNTIF(店舗別サマリ!A:A, TEXT(TODAY(),"yyyy/MM/dd"))
本日の平均完了率:      =AVERAGEIF(店舗別サマリ!A:A, TEXT(TODAY(),"yyyy/MM/dd"), 店舗別サマリ!E:E)
※完了率列(D)は "95%" 文字列なので、集計用に数値列を持たせるのも可
未達店舗(完了率<100%): QUERY で当日かつ未完了数>0 を抽出
```

QUERY 例（当日の未達店舗を一覧）:
```
=QUERY(店舗別サマリ!A:I,
  "select B,C,D,G,H where A = '"&TEXT(TODAY(),"yyyy/MM/dd")&"' and G > 0 order by G desc", 1)
```

## 展開を楽にする方法

### 方法1：テンプレートを複製
1. 完成した1店舗分（コード導入済み・セットアップ済み）を**テンプレート**として保存
2. 新店はこれを「コピーを作成」→ `設定` タブの店舗ID/店舗名だけ変更 → セットアップ実行
3. 100店でも「複製 → IDだけ変更」で量産できる

### 方法2：clasp でコードを一括配布（上級）
`clasp`（Google公式CLI）を使うと、このリポジトリのコードを各店の
Apps Script プロジェクトへコマンドで反映できます。コード修正の横展開が速い。

```bash
npm install -g @google/clasp
clasp login
# 各店スプレッドシートに紐づくスクリプトIDを .clasp.json に設定
clasp push          # apps-script/ の内容をそのプロジェクトへ反映
```

`.clasp.json` の雛形は [`.clasp.json.example`](../.clasp.json.example) を参照。
店舗IDは各店の `設定` タブで持つので、**コードは全店まったく同じ**です（共通コード＋店舗別設定）。

> 100店規模で本格運用する段階では、業務マスターの内容を**本部シートで一括管理**し、
> 各店が取りに行く構成にすると、全店の業務内容を本部から更新できます
> （次の発展フェーズ）。

# 05. 既存のスプレッドシートに反映する（v1 で反映されなかった理由）

## 1. 何が起きていたか

v1 のコードは、次の名前のタブを探して動いていました。

```
業務マスタ / 本日のチェック / 日次ログ / ダッシュボード / 本日の対象（自動）
```

一方、お使いのスプレッドシートのタブは

```
各業務マスター / 今日のチェック / 履歴 / 設定
```

**名前が一致しないため、コードは「無い」と判断して自分用のタブを新規作成**し、
そちらの中だけで動いていました。

その結果、

- `各業務マスター` を編集しても、コードは `業務マスタ` を見ているので気づかない
- `今日のチェック` は誰も更新しないので、いつまでも変わらない

という状態でした。これが「反映されない」の直接の原因です。

さらに、反映のきっかけである **インストール型 onEdit トリガー**は
メニューから一度実行しないと有効になりません。ここも未実行だと、
たとえタブ名が合っていても反映は起きません。

## 2. v2 でどう直したか

### (1) タブは「別名」で探し、あればそれを使う

`Config.gs` の `SHEET_DEFS` に別名を持たせ、
既にあるタブを見つけたらそれを使います（新規作成しません）。

| 役割 | 探す名前（先頭が優先） |
|---|---|
| マスター | `各業務マスター` `業務マスター` `業務マスタ` `各業務マスタ` `マスター` `マスタ` |
| チェック | `今日のチェック` `本日のチェック` `チェック` `デイリーチェック` `今日のタスク` |
| 履歴 | `履歴` `日次ログ` `ログ` `記録` `実績` |
| 設定 | `設定` `設定シート` `セッティング` `Settings` `config` |

全角/半角・空白・記号のゆれも吸収します（`目安（分）` と `目安(分)` は同じ扱い）。
完全一致で見つからない場合は部分一致でも探すので、`今日のチェック（新）` のような
名前でも拾えます。

### (2) 列は「見出しの文字」で探す

「A列＝ID、B列＝区分…」という位置の決め打ちをやめ、
1行目の見出しを読んで列を特定します。

| 項目 | 見出しとして認識する例 |
|---|---|
| ID | `ID` `業務ID` `No` `番号` |
| 区分 | `区分` `カテゴリ` `分類` `タイミング` `時間帯` |
| 業務名 | `業務名` `タスク名` `内容` `項目` `チェック項目` |
| 目安(分) | `目安(分)` `所要時間` `想定時間` |
| 頻度 | `頻度` `実施頻度` `サイクル` `周期` |
| 必須 | `必須` `重要` |
| 備考 | `備考` `メモ` `補足` |
| 有効 | `有効` `使用` `利用` |

**見つからない項目だけ、右端に列を追加**します。
既存の見出し・既存のデータは書き換えません。

### (3) 空欄の自動補完

行を足しただけで「今日のチェック」に出るように、次を自動補完します。

| 列 | 空欄のときの扱い |
|---|---|
| ID | `T01` `T02`… で自動採番（既存IDと重複しない） |
| 区分 | `営業中` |
| 頻度 | `毎日` |
| 目安(分) | `0` |
| 必須 | オフ |
| 有効 | **オン**（チェックを外したときだけ非表示になる） |

> v1 では新しい行の「有効」が FALSE のままになり、追加した業務が
> 出てこないことがありました。ここも直っています。

### (4) 設定はシート上に

店舗名・営業時間・通知先・本部集約IDなどは `設定` タブで編集します。
コードを触る必要はありません。

## 3. 反映の確認手順

1. **🌸 サロン業務 → 🩺 動作チェック（診断）** を実行
2. 「■ 使用中のタブ」が、あなたのタブ名になっているか確認
   ```
   ✅ 業務マスター → 「各業務マスター」
   ✅ 今日のチェック → 「今日のチェック」
   ✅ 履歴 → 「履歴」
   ✅ 設定 → 「設定」
   ```
3. 「■ 自動化トリガー」が全部 ✅ か確認
   （❌ があれば **⏰ 自動化トリガーを設定** を実行）
4. `各業務マスター` に1行足して、`今日のチェック` に出るか確認

## 4. すでに余計なタブができてしまっている場合

v1 が作った `業務マスタ` `本日のチェック` `日次ログ` `本日の対象（自動）` が
残っていると、v2 が**そちらを優先して使ってしまう可能性**があります
（別名リストに含まれるため）。

対処は次のどちらかです。

- **不要なら削除する**（推奨）。`各業務マスター` `今日のチェック` `履歴` だけ残す
- 残したいなら、名前を `旧_業務マスタ` のように変えて、
  別名にヒットしないようにする

削除・改名のあと、**🏗 初期セットアップ** をもう一度実行してください。

## 5. 注意：このリポジトリから直接シートは書き換えられません

この開発環境にはあなたのGoogleアカウントの認証情報がありません
（安全のため渡すべきでもありません）。そのため、外部から直接
スプレッドシートを書き換えることはできません。

代わりに **スプレッドシートに紐づいた GAS がシートを操作する** のが正攻法です。
権限はあなたの承認のもと、あなたのシートの中だけで完結します。

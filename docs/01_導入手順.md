# 01. 導入手順

所要 約5分。既にお使いのスプレッドシートにそのまま入れられます。

## 事前準備
- 対象のGoogleスプレッドシート
- そのシートの編集権限を持つGoogleアカウントでログインしていること

## 手順

### 1. Apps Script を開く
対象スプレッドシートで **拡張機能 → Apps Script**。

### 2. コードを貼り付ける（1ファイルでOK）

`dist/DailyCheck.gs` の中身を**全部コピー**し、最初からある `コード.gs` に
**上書きで貼り付け**て保存（💾）。

> ファイルを分けて管理したい場合は、`apps-script/` の各 `.gs` を
> 同じ名前で作成して貼り付けても構いません（動作は同じ）。
> `appsscript.json` は「⚙ プロジェクトの設定 → マニフェストファイルをエディタで表示する」
> にチェックを入れると編集できます。

### 3. スプレッドシートを再読み込み
シートに戻ってブラウザを再読み込み。数秒後、上部に **🌸 サロン業務** が出ます。

### 4. 初期セットアップ
**🌸 サロン業務 → 🏗 初期セットアップ**

- 初回のみ「承認が必要です」→ アカウント選択 → 「詳細」→「（安全ではないページ）に移動」→「許可」
  （自分のスクリプトを自分のシートで動かすための標準的な承認です）
- 完了すると、**使用するタブ名がダイアログで表示されます**。
  ここが `各業務マスター` `今日のチェック` `履歴` `設定` になっていることを確認してください。

### 5. 自動化トリガーを設定 ★重要
**🌸 サロン業務 → ⏰ 自動化トリガーを設定**

これを実行して初めて、次が有効になります。

- `各業務マスター` の編集 → `今日のチェック` へ**即反映**
- ✓ を付ける → `履歴` へ**自動記録**
- 毎朝（既定6:00）当日分を用意 ／ 毎晩（既定20:30）その日を確定

> **反映されない原因の第1位がこれの未実行です。**

### 6. 動作チェック
**🌸 サロン業務 → 🩺 動作チェック（診断）**

すべて ✅ で「🎉 すべて正常です」と出れば導入完了です。

---

## 設定を変える

`設定` タブで編集します（コードを触る必要はありません）。

| 項目 | 説明 |
|---|---|
| 店舗ID | 本部で一意になるID（例 `STORE_001`） |
| 店舗名 | 表示用の店舗名 |
| 開店時刻 / 閉店時刻 | 例 `11:00` / `20:00` |
| 目標作業時間(分) | 開店前・閉店前それぞれの目標 |
| 未完了アラート送信先 | 空欄なら送信しない |
| 本部集約スプレッドシートID | 空欄なら送信しない |
| 朝の自動リセット時刻(時) | 0〜23（既定 6） |
| 夜の自動確定時刻(時) | 0〜23（既定 20） |
| ダッシュボードを使う | TRUE にすると `ダッシュボード` タブを作成 |

> 時刻を変えたら、**⏰ 自動化トリガーを設定** をもう一度実行してください
> （トリガーの時刻を作り直すため）。

---

## 業務を増やす・減らす

`各業務マスター` を直接編集します。

| 列 | 意味 |
|---|---|
| ID | 空欄なら自動採番されます |
| 区分 | `開店前` / `営業中` / `閉店前`（空欄なら営業中） |
| 業務名 | 表示名。**これが空の行は無視されます** |
| 目安(分) | 想定作業時間（開店前・閉店前の合計が目標判定に使われる） |
| 頻度 | `毎日` `毎回` `平日` `土日` `月`〜`日` `月末` `毎月15日`（空欄なら毎日） |
| 必須 | ✓ でチェック画面に ★ が付く |
| 備考 | 業務名セルのメモ（マウスを乗せると表示）になります |
| 有効 | ✓ の行だけ表示。一時停止したいときは ✓ を外す |

**行を足すだけで、その場で `今日のチェック` に出ます**（空欄は自動補完されます）。

---

## うまく動かないとき

| 症状 | 対処 |
|---|---|
| メニューが出ない | シートを再読み込み。それでも出なければ Apps Script で `onOpen` を1回手動実行 |
| マスターを直しても反映されない | **⏰ 自動化トリガーを設定** を実行 → **🩺 動作チェック** で確認 |
| 見覚えのないタブが増えた | [`05_既存シートへの反映.md`](05_既存シートへの反映.md) の「余計なタブ」を参照 |
| 記録されない | **🩺 動作チェック** で `onEditInstallable` が ✅ か確認 |
| 権限エラー | プロジェクトの設定 → 権限をやり直す |

# 01. 導入手順（コピペ方式）

初回はこの方法が最短・確実です。所要 約5〜10分。

## 事前準備
- 使いたいGoogleスプレッドシート（今お使いのものでOK）
- そのシートの編集権限を持つGoogleアカウントでログインしていること

## 手順

### 1. Apps Script を開く
対象スプレッドシートで **拡張機能 → Apps Script**。

### 2. コードを貼り付ける
`apps-script/` フォルダの各ファイルを、Apps Script エディタに**同じ名前**で作成して貼り付けます。

- 左の「ファイル ＋」→「スクリプト」で新規作成し、名前を合わせる
  （`Config`, `Common`, `Setup`, `Checklist`, `Log`, `Dashboard`, `Menu`, `Triggers`, `CentralSync`）
- 各ファイルに対応する `.gs` の中身を貼り付け
- 最初からある `コード.gs` は空にして使うか、削除して構いません

> `appsscript.json`（マニフェスト）は
> 「⚙ プロジェクトの設定 → 『appsscript.json マニフェスト ファイルをエディタで表示する』」に
> チェックを入れると編集できます。内容を差し替えて保存。

### 3. 店舗情報を設定
`Config.gs` の以下を自店の値に。

```js
STORE_ID:   'STORE_001',   // 例: 渋谷店 → SHIBUYA / STORE_012 など、店舗で一意に
STORE_NAME: '本店',
OPEN_TIME:  '11:00',
CLOSE_TIME: '20:00',
BUFFER_MIN: 10,            // 前後10分の目標
```

保存（💾）。

### 4. スプレッドシートを再読み込み
シートに戻ってブラウザを再読み込み。数秒後、上部メニューに **🌸 サロン業務** が出ます。

### 5. 初期セットアップ
**🌸 サロン業務 → 🏗 初期セットアップ** を実行。

- 初回のみ「承認が必要です」→ アカウント選択 → 「詳細」→「（安全ではないページ）に移動」→「許可」
  （自分が作ったスクリプトを自分のシートで動かすための標準的な承認です）
- 完了すると `本日のチェック / ダッシュボード / 業務マスタ / 日次ログ` が作られます

### 6. 自動化トリガーを設定
**🌸 サロン業務 → ⏰ 自動化トリガーを設定** を実行。

これで以下が自動化されます。
- チェックの ON/OFF を「日次ログ」へ自動記録
- 毎朝6:00 に前日を確定 → 当日分にリセット
- 毎晩20:30 に本日分を確定（＋設定していれば本部送信・未完了メール）

## 業務を増やす・減らす
`業務マスタ` シートを直接編集します。

| 列 | 意味 |
|---|---|
| ID | 一意のID（例 T13）。重複しないように |
| 区分 | 開店前 / 営業中 / 閉店前 |
| 業務名 | 表示名 |
| 目安(分) | 想定作業時間（開店前・閉店前の合計が目標判定に使われる） |
| 頻度 | 毎日 / 随時（どちらも毎日チェック対象） |
| 必須 | ✓ で必須（チェック画面に ★ が付く） |
| 備考 | メモ |
| 有効 | ✓ の行だけチェック画面に出る（一時停止は ✓ を外す） |

編集後、翌朝の自動リセット、または **▶ 本日のチェックを開く** で反映されます。

## うまく動かないとき
- メニューが出ない → シートを再読み込み。それでも出なければ Apps Script で `onOpen` を1回手動実行
- 記録されない → **⏰ 自動化トリガーを設定** を実行したか確認
- 権限エラー → 承認をやり直す（プロジェクトの設定 → 権限）

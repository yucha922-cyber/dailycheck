# 03. 運用フロー（1日の流れ）

営業時間 11:00〜20:00。目標は「開店前・閉店前の作業をそれぞれ10分以内」。
（時間・目標は `設定` タブで変更できます）

## タイムライン

| 時間帯 | 区分 | やること | チェック画面 |
|---|---|---|---|
| 〜11:00（開店前） | 開店前 | 清掃 / カルテ準備 | 済んだら ✓ |
| 11:00〜20:00 | 営業中 | カルテ記入 / 39メール / 口コミ返信 / SATTOU入力 / 前日リマインド / ブログ作成 | 施術の合間に、やった時点で ✓ |
| 20:00〜（閉店前） | 閉店前 | 売上確認 / 現金確認 / 事業計画更新 / カルテスクリプト | 済んだら ✓ |
| 退勤時 | — | 院を出た時刻を記録 | 最終行「帰宅時間」の `完了時刻` 欄に入力（例 20:30） |
| 20:30 | — | 自動で今日の分を確定 → `履歴` へ保存（＋本部送信） | 自動 |
| 翌6:00 | — | 自動で当日分にリセット | 自動 |

## コツ：営業時間内に終わらせる設計

1. **営業中タスクを「溜めない」**
   39メール・SATTOU入力・カルテ記入は、発生した瞬間に処理して ✓。
   閉店前にまとめてやろうとすると10分では終わりません。

2. **閉店前タスクは「確認系」だけに絞る**
   売上確認・現金確認・事業計画更新のように、営業中に下ごしらえ
   （売上入力・経費入力）を済ませておけば、閉店前は照合と確認だけになります。

3. **ダッシュボードの「想定作業時間」で目標を管理**（`設定` で有効化したとき）
   開店前・閉店前の目安時間合計が10分を超えていれば、
   タスクの一部を「営業中」へ移す・自動化する・頻度を落とす、を検討。

4. **未完了は翌日に持ち越さない**
   夜の確定時、未完了があればメール通知（`設定` タブの「未完了アラート送信先」を入力したとき）。
   何が終わらないのかを毎日データで把握し、業務そのものを見直します。

## 週次のふりかえり（推奨）
- `履歴` タブ、またはダッシュボードの「◯月の完了率（1ヶ月間）」を確認
  （当月の1日から今日までが1行ずつ並びます）
  - H列 … その日 100% に達した時刻（最後に ✓ を付けた時刻）
  - I列 … 帰宅時間（院を出た時刻）
  - この2つの差が「業務は終わっているのに院に残っている時間」です
- いつも落ちる業務があれば、原因を1つ潰す（手順化・自動化・担当変更）
- `各業務マスター` の目安時間を実態に合わせて更新

## 月次のふりかえり（先月との比較）
ダッシュボードの下（30行目以降）に **「🗂 月次アーカイブ（先月と今月の比較）」** が出ます。

```
        B〜F 列                     H〜L 列
   2026年8月（先月）              2026年9月（今月）
   平均完了率 84% ／ …            平均完了率 92% ／ … ／ 前月比 +8pt
   日付 完了率 推移 100%達成時刻 帰宅時間   日付 完了率 推移 100%達成時刻 帰宅時間
   08/01(土) …                   09/01(火) …
```

- 各月の見出しの下に **平均完了率／100%達成の日数／平均帰宅時間**、
  今月には **前月比（◯pt）** が出ます
- **月が変わると自動で1つずつ左へ送られます**（9月が終われば、10月と並んで9月がここに残ります）。
  元データは `履歴` タブなので、書き写す作業は要りません
- もっと前の月まで並べたいときは、`設定` タブの **「比較表示する過去の月数」** を
  2〜6 に変えてください（0 にすると比較表を出しません）

## 手動操作メニュー
| メニュー | いつ使う |
|---|---|
| ▶ 今日のチェックを開く | チェック画面へ移動（日付が変わっていれば作り直す） |
| 🔄 マスターの内容を反映 | `各業務マスター` を編集したのに変わらないとき |
| ✅ 今日の分を確定（履歴に保存） | 早く閉めたい日に手動で締める |
| 🩺 動作チェック（診断） | 反映されない・記録されないときの原因調査 |
| 📊 ダッシュボードを更新 | 最新の集計を見たいとき |
| ☁ 本部へ今日のサマリを送信 | 本部連携時、手動で送りたいとき |
